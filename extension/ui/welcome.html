01 / PIN

Pick your home base.

Right-click a normal webpage’s Chrome tab and choose Pin. Anchor enables protection automatically; confirm the page is connected.

02 / CLICK

Browse like you mean it.

Click an ordinary link. Choose a new tab, a new window or a browsing window for eligible links.

03 / ADJUST

Make it yours.

Use Workspaces for a solo dashboard or up to four real Chrome windows arranged in a grid. Pause or release whenever needed.

Pin the tab, not just the extension icon. Chrome’s puzzle-piece menu can pin Anchor’s icon to the toolbar. To protect a webpage automatically, right-click the webpage’s tab and select Pin.

Layouts use real Chrome windows, not embedded panes. Link protection is not a universal navigation lock; pause for login and maintenance.
