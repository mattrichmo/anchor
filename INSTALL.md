ANCHOR 2.0 — KEEP YOUR PLACE. EXPLORE SOMEWHERE ELSE.

INSTALL
Disable the old Anchor / Pinned Tab Link Guard copy.
Extract this package into a permanent directory.
Chrome -> chrome://extensions -> Developer mode -> Load unpacked.
Select Anchor/extension, not Anchor and not a ZIP.
Refresh existing webpages. Pin the actual webpage tab, not only Anchor's toolbar icon.
Open Anchor; confirm the current page is connected before relying on protection.
No build step, API key or server is needed to use the included extension.

SINGLE DASHBOARD
Popup -> Where should links open? -> A new window for each link or My browsing window.
Choose Follow the link or Stay here independently.
Make dashboard window moves your live page rather than reopening its URL.

FOUR DASHBOARDS
Workspaces -> Add up to four open pages -> 2 x 2 grid -> My browsing window -> Open & arrange.
The grid uses four real Chrome windows, NOT four panes in one browser window.
One window keeps multiple protected tabs together but only the active tab is visible.
Pause 5 minutes for login/maintenance. Release restores earlier tab choices without closing pages.

UPGRADE
To retain an unpacked extension identity, replace files inside the SAME previously loaded
extension folder with this package's extension/ contents, then Reload and refresh webpages.
Export settings first. A different folder may create a new extension identity.
