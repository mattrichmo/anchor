# Changelog

## 2.0.0 — 2026-10-03

- Separate new-tab, new-window-per-link and designated browsing-window destinations. Per-tab focus choice independent of routing.
- Solo dashboard action adopts/moves the existing page; saved workspaces support up to four anchors and 20 definitions.
- Real-window collection, columns, rows, 2×2 and focus layouts; optional monitor permission, spacing validation, readback warnings, explicit rearrangement.
- Native extra-tab relocation for reserved windows; conservative auth/browser exceptions, pause/release, no forced closed-page restoration.
- Bounded local branch provenance and return-to-source; explicit working copy.
- Document/revision/guard-version readiness acknowledgement; stale state rejection, preflight refresh and disconnected known-protected fail-closed behavior. The asynchronous pin/click boundary is documented, not claimed eliminated.
- Source, destination and UI mutation queues; persistent pending-operation journals and manual acknowledgement for uncertain creations. No URL deduplication or automatic POST replay.
- Validated local imports, reserved identity rejection, duplicate live-tab binding checks, consumed move leases, safe editor rebinding after save.
- Expanded worker/policy, DOM/UI and runnable installed-browser tests; refreshed UI/help/privacy/store/website materials.

## 1.0.0 — supplied baseline

Pinned/manual link protection, three policy modes, per-origin rules, opt-in GET/hash behavior, conservative experimental recovery, local-only settings, original brand and store kit. The preceding source review identified the pin-state timing and readiness issues addressed in this release.
